**Title:-**

Kids ToyJoy Landing Page.

**Description:-**

Kids ToyJoy is a modern and responsive landing page designed for a kids’ toy brand. Built using HTML, CSS, JavaScript, and Bootstrap, the project focuses on creating an attractive user interface with a smooth and user-friendly experience. It features a colorful layout, interactive sections, clean navigation, and a mobile-friendly design to ensure accessibility across all devices.

**How we can run this project:-**

Open the project folder in Visual Studio Code
Open the index.html file
Right-click on the file and select Open with Live Server
The project will automatically open in your browser
